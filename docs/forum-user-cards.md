# 论坛身份展示

匹配结果使用论坛头像和用户名片，仍只返回当前查看者有权查看的匹配对象。管理员资料页面继续受原有权限限制。

使用 Discourse 原生 `DUserLink`、`DUserAvatar` / `dAvatar` 和 `data-user-card`，遵循论坛用户资料可见性设置。只序列化已授权身份的 `id`、`username`、`avatar_template`，不带邮箱等私有字段。无需数据迁移。
