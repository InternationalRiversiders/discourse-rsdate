# 迁移对照

| 旧版能力 | 原生插件 |
| --- | --- |
| Discourse SSO、校友组、学校校区配置 | 论坛当前用户和认证组，实时检查 active / suspended / admin |
| 首页下一步提示、报名/暂停、等待状态 | 个人主页；资料保存与报名分离，未匹配继续留池 |
| 资料字段与验证 | 昵称 2–24、时间 4–120、介绍 10–280；兴趣最多 12 个、每个 20 字；相同枚举 |
| 模块列表、必填/选填、题目说明 | 模块列表与单模块页面；完成/重填状态，答案独立保存 |
| 管理员编辑问卷草稿 | 相同 `题目##说明||选项|选项`，省略选项使用五级量表；支持排序、删除和停用 |
| 按版本判定有效提交 | revision 控制；导入时以旧 submittedAt / 模块 updatedAt 判定 |
| 管理参与者 | 搜索、分页、暂停/恢复、当前对象、必填进度 |
| 匹配池预览 | 后台执行，展示分数、理由和未匹配成员，不修改报名或发送通知 |
| 自动/手工整池发布 | 相同权重与最大人数优先；事务锁与唯一周期 |
| 管理员指定配对 | 保留旧版偏好覆盖能力，补充界面确认；需入池且完成必填 |
| 周期发布 | 同一上海时区周期编号，支持延迟执行与幂等 |
| 当前匹配、历史、模块接近度 | 全量导入、分页、对方论坛链接、原说明与发布时间 |
| 清除匹配 | 双方当前记录及本轮历史撤回，双方恢复入池，其他历史保留 |
| 文本 embedding | 导入旧向量；可选后台生成，资料改变使旧向量失效 |
| 早期单版本问卷 | 保留归档，不与现行模块问卷重复显示 |
| 提醒 | 新增仅站内通知，导入不重放 |
| 隐私与账号生命周期 | 本人导出、删除/匿名化清理、合并不转移报名意愿 |

相比旧实现，原生版还会排除已停用/封禁或失去认证权限的用户、校验答案所属选项，并在重新配对时同时撤下旧关系两端的“当前结果”。文本向量只比较相同模型。历史本身保留，避免这些保护改变已经发布的旧结果。

这次只部署到隔离私有测试论坛。正式域名、旧应用和线上发布流程尚未切换。
